# PrivaFlow Workflow: brand-id-gen
> Generated by HeQheru | October 3, 2026
> Purpose: Generate family of brand identity versions for consideration

---

## Workflow Overview

**Name:** brand-id-gen
**Tier:** L2 (Orchestration)
**Trigger:** Manual (mcctl) or Scheduled
**Output:** Multiple brand identity variations packaged for review

---

## Workflow Definition

```yaml
name: brand-id-gen
description: Generate brand identity variations using HeQheru creative agent
version: 1.0.0
tier: 2

inputs:
  - name: project
    type: string
    required: true
    description: "Project name (e.g., drumstr)"
  - name: brand_framework_path
    type: string
    required: true
    description: "Path to brand framework document"
  - name: output_dir
    type: string
    required: true
    description: "Directory to save generated assets"
  - name: num_variations
    type: integer
    default: 3
    description: "Number of logo variations to generate"
  - name: include_hero_prompts
    type: boolean
    default: true
    description: "Include hero image prompt generation"

steps:
  - id: read-framework
    agent: heqheru
    action: read-file
    params:
      path: "{{ inputs.brand_framework_path }}"
    output: brand_context

  - id: generate-logo-variations
    agent: heqheru
    action: creative-generation
    params:
      task: "Generate {{ inputs.num_variations }} distinct logo concepts"
      context: "{{ steps.read-framework.output }}"
      requirements:
        - "Each variation must be unique in concept"
        - "Output as SVG code"
        - "Include design rationale"
        - "Follow brand color palette"
        - "Work at small sizes (favicon-ready)"
    output: logo_variations

  - id: generate-hero-prompts
    agent: heqheru
    action: creative-generation
    params:
      task: "Generate hero image prompts"
      context: "{{ steps.read-framework.output }}"
      requirements:
        - "Primary prompt (recommended)"
        - "2-3 alternative variations"
        - "Negative prompt for SD"
        - "Technical specifications"
        - "Usage notes for landing page"
    output: hero_prompts
    condition: "{{ inputs.include_hero_prompts }}"

  - id: package-assets
    agent: sebeq
    action: file-operations
    params:
      task: "Package generated assets"
      operations:
        - "Create output directory structure"
        - "Write SVG files for each logo variation"
        - "Write prompt documents"
        - "Create BRAND-IDENTITY-OPTIONS.md summary"
        - "Generate production specs"
    output: package_result

  - id: notify-review
    agent: auseq
    action: event-emission
    params:
      event: "brand-identity-ready"
      data:
        project: "{{ inputs.project }}"
        output_dir: "{{ inputs.output_dir }}"
        num_variations: "{{ inputs.num_variations }}"
        timestamp: "{{ now }}"

outputs:
  - name: output_dir
    type: string
    description: "Directory containing all generated assets"
  - name: logo_variations
    type: array
    description: "List of logo variation file paths"
  - name: hero_prompts
    type: string
    description: "Path to hero image prompts document"
  - name: summary
    type: string
    description: "Path to BRAND-IDENTITY-OPTIONS.md"
```

## Usage

### Command Line
```bash
mcctl privaflow "Run brand-id-gen workflow for drumstr project. Brand framework at /Users/transformoses/repos/drumstr/docs/DRUMSTR_BRAND_FRAMEWORK.md. Output to /Users/transformoses/repos/drumstr/creative/. Generate 3 logo variations and include hero prompts."
```

### Direct Trigger
```bash
mcctl trigger-flow brand-id-gen \
  --project drumstr \
  --brand-framework-path /Users/transformoses/repos/drumstr/docs/DRUMSTR_BRAND_FRAMEWORK.md \
  --output-dir /Users/transformoses/repos/drumstr/creative/ \
  --num-variations 3 \
  --include-hero-prompts true
```

---

## Agent Roles

### HeQheru (Creative Generation)
- Reads brand framework for context
- Generates logo concepts with rationale
- Creates detailed hero image prompts
- Ensures consistency with brand identity

### Sebeq (File Operations)
- Creates directory structure
- Writes SVG files
- Packages documents
- Handles file system operations

### Auseq (Event Listening)
- Emits "brand-identity-ready" event
- Triggers notification workflows
- Logs completion for audit trail
