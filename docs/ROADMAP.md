## Technical Roadmap

### Phase 0 (Current)
- Static HTML/CSS/JS (landing page)
- Public MiroTalk demo (video)
- Manual payments (MoneyDevKit dashboard)
- GitHub (code, issues, discussions)

### Phase 1
- Backend: Node.js + Express + PostgreSQL
- Frontend: React/Next.js
- Auth: Nostr (NIP-07, NIP-98)
- Payments: MoneyDevKit + Lightning
- Video: HiveTalk + MiroTalk (fallback)

### Phase 2
- Mobile: React Native + Expo
- Push: Firebase FCM
- Offline: AsyncStorage + sync
- A/V: Native WebRTC

### Phase 3
- AI: Facilitator matching (ML)
- Multi-room: SFU architecture
- Analytics: PostHog + Mixpanel
- Community: Nostr relay (relay.drumstr.app)

### Phase 4
- Marketplace: Stripe Connect (optional)
- Merchandise: Shopify integration
- i18n: next-intl
- Events: Calendar + RSVP

### Phase 5
- Enterprise: SSO, RBAC, audit logs
- API: OpenAPI + SDK
- White-label: Multi-tenant architecture
- Franchise: Partner portal
